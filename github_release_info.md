## Có gì mới

- Bổ sung Phoenix Reffaella, Severian Lowell và ảnh trang phục dùng offline.
- Bổ sung quy trình tạo bản phát hành cho Windows và macOS.

## Tải ứng dụng

- **Windows x64:** tải và chạy `Visual-Mods-Manager-Setup.exe`. Có bản ZIP portable nếu bạn muốn tự giải nén.
- **macOS Apple Silicon:** tải ZIP có hậu tố `macos-arm64`.
- **macOS Intel:** tải ZIP có hậu tố `macos-x86_64`.

Giữ nguyên các thư mục Mods và Download khi cập nhật. Hướng dẫn sử dụng nằm trong README của repository.
